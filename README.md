# 🚀 RecuvaX – File Recovery Website

RecuvaX is a web-based file recovery project designed with a clean and user-friendly interface.

## ✨ Features
- User-friendly website interface
- Dashboard page
- Responsive styling
- HTML, CSS and JavaScript-based frontend

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
RecuvaX/
│
├── index.html
├── style.css
├── script.js
├── dashboard.html
├── dashboard.css
├── dashboard.js
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the RecuvaX folder.
3. Open `index.html` in your browser.
